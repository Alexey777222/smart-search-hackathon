# Умный поиск Softline
Веб-стенд для хакатона «ИИкузница». Поиск работает по каталогу организатора из 136 040 предложений ПО и оборудования. Стенд исправляет опечатки, группирует варианты лицензий по продуктовым семействам и формирует топ‑4 из разных семейств. Прямые совпадения, аналоги и сопутствующие товары имеют отдельные пометки. При подборе сопутствующих товаров система проверяет обязательные характеристики и показывает основание рекомендации.
По запросу «сервер» оборудование, комплектующие и ПО выводятся отдельно. Запрос «ПО для сервера» сужает выдачу до программного обеспечения.
В основе стенда — Python, FastAPI, SQLite и RapidFuzz. Обычный поиск работает по локальному индексу. Консультант «Помочь с выбором» на публичном стенде работает в режиме имитации провайдера.
[Открыть веб-стенд](https://search-demo.micromarket-control.ru)

## Наработка до спринта
До старта был создан локальный прототип на 25 синтетических позициях ПО. В нём сравнивались точный поиск и поиск с обработкой сокращений, нечётким сопоставлением и проверкой версий и редакций. За время спринта были добавлены импорт каталога организатора, поисковый индекс, группировка предложений, веб-интерфейс, проверка на запросах организатора и топ‑4 с проверкой сопутствующих товаров.

## Запуск учебного прототипа

Локальный прототип поиска по вымышленному каталогу из 25 позиций ПО.
Два режима: **baseline** (точное совпадение) и **smart** (сокращения +
RapidFuzz + фильтр версий/редакций). Один внешний пакет — RapidFuzz.

### Требования и установка (PowerShell, Windows)

Требуется Python 3.11+.

```powershell
cd <папка проекта>
python -m pip install rapidfuzz
```

### Команды

```powershell
# поиск: показывает результаты обоих режимов
python search.py "текст запроса"

# настройка порога RapidFuzz на отдельном тюнинг-наборе (не контрольном)
python tune.py            # перебор порогов
python tune.py --apply    # записать лучший порог в config.py

# итоговая оценка обоих режимов на контрольном наборе
python evaluate.py
```

### Формат данных

#### data/catalog.csv

| поле | описание |
|---|---|
| `id` | уникальный ID позиции, например `SW-001` |
| `name` | название продукта; в каталоге есть похожие названия и разные редакции одного продукта (`TaskFlow Pro 2024` / `TaskFlow Pro 2023` / `TaskFlow Home 2024`, `PixelDesk Studio` / `PixelDesk Studio Portable` / `PixelDesk Lite`) |

#### data/queries.csv — контрольный набор (30 запросов, только для итогового прогона)

| поле | описание |
|---|---|
| `query` | текст запроса |
| `expected_ids` | допустимые ID через `\|`; пустое значение — подходящего товара нет |
| `frequency` | условная частота запроса (для отчёта) |
| `context` | контекст использования (для отчёта) |
| `case_type` | тип случая: `exact`, `typo`, `abbreviation`, `word_swap`, `version`, `edition`, `missing` |

#### data/tuning_queries.csv — отдельный тюнинг-набор

Тот же принцип разметки, но используется **только** `tune.py` для подбора
порога. Контрольные запросы в настройке не участвуют.

### Как работает режим smart

1. Точное совпадение с названием после нормализации (регистр, пробелы).
2. Если точного нет — раскрытие известных сокращений из словаря
   `config.ABBREVIATIONS` (`pwd -> password`, `txt -> text`, `prof -> professional`, ...)
   и повторный поиск точного совпадения.
3. Сравнение с названиями через RapidFuzz (`WRatio`). Кандидаты ниже порога
   (подобран `tune.py`, сейчас 55) отбрасываются. Если запрос явно содержит
   версию (год) или редакцию (`pro`, `lite`, `x64`, `server`, ...), позиции с
   несовместимой версией/редакцией исключаются.
4. До 5 результатов по убыванию сходства. При слабом совпадении —
   «ничего не найдено». Балл RapidFuzz показывается как **мера сходства**
   (похожесть строк, а не уверенность в выборе).

### Демо (три сценария)

```powershell
# 1. Опечатка исправляется: Pr0 -> TaskFlow Pro 2024 (SW-001)
python search.py "TaskFlow Pr0 2024"

# 2. Сокращение раскрыто: pwd mgr -> SecurePass Password Manager (SW-022)
python search.py "securepass pwd mgr"

# 3. Отсутствующий товар -> «ничего не найдено» в обоих режимах
python search.py "Photo Face Retouch"
```

Дополнительно: `python search.py "TaskFlow Pr0 2023"` — запрос конкретной
редакции не подменяется другой (SW-002 находится, SW-001 отфильтрован по году).

### Ожидаемые цифры контрольного прогона

- правильным товаром заканчивается топ-5: baseline 10/26 (38.5%), smart 26/26 (100%);
- ложных выдач на запросах без товара: smart 0/4;
- в отчёте также печатается таблица самых частых запросов без результата.
